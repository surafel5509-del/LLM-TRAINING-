# Datasets

The current release accepts CSV, JSON and JSONL. Uploads are size-limited, filenames are normalized, and storage paths are generated by dataset UUIDs.

Validation checks empty data, missing target, missing values, duplicates, and unsupported formats. Tabular preprocessing uses one-hot encoding for categorical features, finite-value cleanup, median numeric imputation, and standardization fitted on the training split only.

The feature schema and scaler parameters are persisted with trained artifacts so inference uses the same transformation.
